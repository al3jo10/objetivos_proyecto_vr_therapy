VR Therapy Center

Una nueva era en la rehabilitación física. Hacemos que la terapia sea divertida, accesible y eficiente para todas las edades.

Diseñado para el Paciente

🥇

Comodidad Primero

La prioridad #1 es cero mareo. El diseño por defecto es sentado, con teletransporte y giro "snap-turn" para una accesibilidad total.

✋

Interacción Accesible

UI simple con iconos grandes. El agarre "toggle" (presionar una vez) evita la fatiga en manos con debilidad.

🌌

Entorno Amigable

Entornos brillantes, coloridos y relajantes. Evitamos diseños "clínicos" u "hospitalarios" para reducir la ansiedad.

La Experiencia del Paciente

Paso 1

Tutorial de Bienvenida

Una voz guía enseña a moverse y agarrar en un entorno seguro.

↓
Paso 2

Sala Inicio (Hub Central)

↓
Paso 3

Salas de Actividades

Minijuegos terapéuticos diseñados para objetivos específicos.

El Corazón de la Terapia

Cada actividad es un "Exergame" diseñado para un objetivo terapéutico. Selecciona una actividad para ver su perfil de enfoque.

Rendimiento y Plataforma

Plataformas Objetivo

El desarrollo se centra en la plataforma Meta Quest 2 debido a su gran base instalada, asegurando compatibilidad con Quest 3.

📈

FPS Objetivo: 72-90

Un framerate estable es vital para prevenir el mareo.

💡

Iluminación Optimizada

Uso de "Baked Lighting" para máximo rendimiento en móvil.

👁️

Renderizado SPIR

Single-Pass Instanced Rendering para renderizar ambos ojos a la vez.

Estrategia de Validación

1

Prototipo de Confort

Probar solo locomoción. Métrica: Cero mareos.

2

Prototipo de Interacción

Probar agarre "toggle" y UI. Métrica: Cero fatiga.

3

Bucle de Juego

Probar una sala completa con audio y feedback.

✓

Validación Clínica

Pruebas supervisadas por fisioterapeutas reales.
